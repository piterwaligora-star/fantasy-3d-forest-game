# ⚔️ FANTASY 3D PIXEL FOREST - ADVANCED EDITION ⚔️

## 🎮 Ultimate Fantasy Game Experience

A fully-featured 3D fantasy RPG built with Three.js featuring:

### ✨ Features (10x BETTER)

#### 🎨 **Advanced Graphics**
- High-resolution shadows (4096x4096)
- Advanced lighting system with multiple light sources
- Particle effects for attacks, spells, and environmental effects
- Weather system (Clear, Rain, Mist, Storm)
- Dynamic material properties with metallic and emissive surfaces
- Real-time minimap with player/enemy tracking

#### ⚔️ **Combat System**
- Click-based melee attacks with damage calculation
- Spell casting system (Q key) with cooldowns
- Enemy AI with detection and attack patterns
- Damage numbers and hit effects
- Health and Mana system with regeneration

#### 👥 **NPCs & Interactions**
- 8 unique NPCs with different classes
- Interactive dialogue system
- Unique visual designs per NPC type
- RPG conversation system

#### 🎯 **Enemies**
- 4 different enemy types (Goblin, Skeleton, Troll, Wraith)
- 15 spawned enemies with AI behavior
- Enemy detection and patrol systems
- Loot and XP rewards

#### 📊 **RPG Mechanics**
- Level and XP system
- Health and Mana bars with stats
- Stamina system with sprint
- Equipment and inventory planning
- Real-time stats display

#### 🗺️ **World Building**
- Advanced multi-layer forest with 16+ trees
- Mystical pillars and magical structures
- Cave systems
- Varied terrain and environmental details
- Day/night cycle ready

#### 🎵 **Audio Ready**
- Web Audio API integration
- Sound effect framework
- Music system foundation

### 🎮 Controls

| Control | Action |
|---------|--------|
| **W/A/S/D** | Move |
| **Mouse** | Look around |
| **Space** | Jump |
| **Shift** | Sprint |
| **Left Click** | Melee Attack |
| **Q** | Cast Spell |
| **R** | Reload (Restore HP/Mana/Stamina) |
| **M** | Map (view minimap) |
| **P** | Pause |
| **ESC** | Exit |
